# Web Engineering Assignment No. 1

This is a personal portfolio website created as part of **Web Engineering Assignment No. 1** using only **HTML** (with inline styling, as per the assignment requirement). It includes multiple sections structured semantically.

## 📄 Pages Included

- **Home Page** – Introduction to the webpage with meta and semantic tags.
- **My Hobbies** – Ordered and unordered lists, and a table of hobbies and favorite games.
- **My Favorite Media** – Social media section with favorite video links and layout using <div>.
- **Contact Page** – Contact information, Google Maps location link, and group member ID.

## 👨‍💻 Technologies Used

- HTML5 (Semantic structure)
- Inline styling (No CSS files)
- Tables, lists, div layout, and external links
